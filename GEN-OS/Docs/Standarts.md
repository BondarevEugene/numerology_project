Принципы разработки GEN-OS

Мы работаем как над промышленной платформой.

1. Один модуль — одна ответственность

Каждый файл имеет одну чёткую роль.

2. Python First

Вся бизнес-логика живёт в Python.

HTML — представление.

JS — минимальный контроллер.

CSS — единый дизайн.

3. Типизация

Везде, где возможно:

dataclass
Enum
typing
pathlib
logging
4. Документирование

Каждый файл начинается единым заголовком GEN-OS.

5. Отказоустойчивость

Каждый сервис:

валидирует вход;
пишет лог;
выдаёт понятные исключения;
не падает на одном повреждённом файле.
6. Тестируемость

Каждый модуль должен быть пригоден для unit-тестов.

7. Красота кода

Никаких магических строк.

Никаких глобальных переменных.

Никаких "TODO потом".

весь код будет соответствовать примерно следующему уровню:

Python 3.11+
dataclasses
typing
pathlib
logging
SOLID
DRY
Enterprise Docstrings
отказоустойчивость
поддержка Windows/Linux
единый стиль GEN-OS
